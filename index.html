SpaTiTan — Installation

Cette page installe le firmware SpaTiTan directement depuis votre navigateur, via un simple câble USB.

⚠️ Cette opération réinitialise entièrement l'appareil (identifiants WiFi/MQTT, planning, sécurité). Vous devrez reconfigurer votre spa après l'installation, comme pour un appareil neuf.
Votre navigateur ne supporte pas l'installation via USB (Web Serial). Utilisez Google Chrome ou Microsoft Edge sur ordinateur.

Prérequis : câble USB relié à l'appareil, navigateur Chrome ou Edge (Web Serial non supporté par Firefox/Safari).

This page only flashes your device — it does not expose any project source code.
Cette page ne sert qu'à flasher votre appareil — elle ne donne accès à aucun code source du projet.
